# Tactic Dock R1.4.2 — DeX-only lifecycle

**User report:** Dock appears at the bottom of the Samsung phone while typing. This is a P0 behavior bug, even if pop-up notifications were already display-scoped.

## Runtime policy
1. Entire Dock UI stays absent if DeX is not confirmed and a single live external display is not present.
2. Samsung "desktopmode" system service `getDesktopModeState()` with enabled/dual display type is first choice; Samsung's documented `Configuration.semDesktopModeEnabled` flag is fallback if reflection unavailable.
3. HDMI screen mirroring and standalone phone mode MUST NOT show any Dock, handle, corners, app menu, quick panel, or notification overlay.
4. All overlays are bound via `createDisplayContext(external)` with NO default-display fallback.
5. Register DisplayManager listener and enter/exit-DeX receiver even before initial runtime, to support connection later.
6. On disconnect, remove tracked overlays immediately. Retry several times during initial HDMI/DeX negotiation.
7. Accessibility remains installed/enabled for transition detection. Never change phone SystemUI/heads-up.
8. Handle actual external display ID on every attach/reconnect. Never hardcode IDs.

## Automated verification
- Unit tests cover phone only, HDMI mirroring, DeX dual mode, non-Samsung, multiple displays, disconnection.
- GitHub Actions: debug APK, tests, build. Physical DeX state must be verified separately.
