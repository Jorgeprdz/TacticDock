# Tactic Dock R1.4 — Validation

The launch resolver uses the attached dock's real display, then its display context, then a uniquely identified external display. No external display means no launch onto the phone.

Public Android APIs cannot reliably move an already-running task to another display. Tactic Dock blocks and informs the user when a task's actual display differs from its target or cannot be verified. A requested display is not the same as a verified launched display. Third-party apps and DeX can override ActivityOptions; logs distinguish requested and observed outcomes where task inspection is allowed.
