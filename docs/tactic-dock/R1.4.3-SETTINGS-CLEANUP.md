# Tactic Dock R1.4.3 — DeX-only settings cleanup

The old SmartDock preferences included Android-x86/phone/secondary launcher
settings, root and SystemUI mutations, hot corners, audio events, obsolete
portrait layouts, and app-launch controls that do not belong in a pinned
macOS-like Samsung DeX Dock.

## Visible configuration
1. Dock: visible application count, icon packs.
2. Appearance: theme, custom color (only for custom theme), icon shape,
   glass opacity.
3. Apps: launcher icon, columns, launch mode, hidden apps.
4. Notifications: DeX-only floating notifications, timeout, excluded
   apps, notification panel, notification listener settings.
5. Diagnostics/backup: current display IDs, export and import preferences.
6. About: Tactic Dock GitHub repository, original SmartDock credit, license.

The actual stored preferences are NOT erased; they can be restored by user
and existing hidden defaults are unchanged. A visible setting must have an
active corresponding handler. The pinned DeX-only Dock does not show phone
gesture/handle or inactive dock-height controls.

Removed old first-launch DonateDialog and DockLayoutDialog from MainActivity.
Permissions remain in the toolbar, not a misleading fake enable switch.
